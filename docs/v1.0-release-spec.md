## What v1.0 is

A **launch cut** for a KRW-only fashion bag marketplace — not feature-complete.

| Property | Spec |
|----------|------|
| Currency | **KRW only** — `*_cents` fields are whole won |
| Customer flow | Browse catalog → PDP → cart → checkout session → order → Stripe card pay → `paid` → ops ship → `in_transit` → stock committed |
| Manager flow | Catalog/coupon admin, order ship, Bypass payment (`payment.bypass`), Telegram ops alerts |
| Auth | Login → refresh → access JWT (RS256 + JWKS); permissions on access tokens |
| Deploy target | AWS ECS on EC2, ALB HTTPS, RDS PostgreSQL, sibling frontends on same ALB |

### Money path (must work end-to-end)

```text
dupli1-web → gateway → cart (lines + server prices)
                    → order (checkout session → order, server prices)
                    → payment (Stripe Checkout or Bypass)
                    → NATS payment.succeeded → order paid
                    → manage-web ship → in_transit + inventory commit + soldCount
```

### Explicitly out of v1.0

Guest cart, automated refunds, Bitcoin, co-view recs, manager settings API, email/SMS, chat/analytics, legacy API alias **removal** (aliases may stay until v1.2), zerolog/sessions/access-control hardening (→ **v1.1**). See [v1-release-plan.md](v1-release-plan.md) § D and [v1.1-release-plan.md](v1.1-release-plan.md).
